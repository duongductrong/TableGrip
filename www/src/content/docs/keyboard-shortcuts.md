TableGrip is built to be driven from the keyboard. Press <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>/</kbd> in the app to see this
list, and change any shortcut in [Settings → Keymap](/docs/settings#keymap).

## Keymap presets

Coming from another tool? **Settings → Keymap → Preset** switches a set of shortcuts at once:

| Preset | Changes |
| --- | --- |
| **TableGrip** | The defaults above |
| **DataGrip / IntelliJ** | Cancel query: <kbd>⌘</kbd> <kbd>F2</kbd> · Go to anything: <kbd>⌘</kbd> <kbd>O</kbd> |
| **VS Code** | Agent: <kbd>⌃</kbd> <kbd>⌘</kbd> <kbd>I</kbd> · Next / previous tab: <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>→</kbd> / <kbd>←</kbd> · Duplicate: <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>↓</kbd> · Delete line: <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>K</kbd> · Move line: <kbd>⌥</kbd> <kbd>↑</kbd> / <kbd>↓</kbd> · Reformat: <kbd>⌥</kbd> <kbd>⇧</kbd> <kbd>F</kbd> · Replace: <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>F</kbd> (<kbd>Ctrl</kbd> <kbd>H</kbd> on Windows / Linux) |

## Change a shortcut

In **Settings → Keymap**, search for an action or a key, click its shortcut and press the new one. TableGrip warns
when the new shortcut clashes with another action, and each action can be reset on its own. Your changes are saved as
`keyBindings` in `settings.json`.
